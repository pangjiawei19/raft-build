# 按职责和授权确定验收人的真实验收

历史记录：下文描述当时的自定义流程。统一验收和主消息汇总规则已于 2026 年 11 月 17 日撤回，当前行为见[Agent 任务与用户待答事项](./agent-task-review-and-user-questions.md)。

日期：２０２６年１１月６日。

## 调整范围

将上一轮绑定 PM 的协作约定改为通用规则。新增和修改的 Agent 提示使用英文，与原有提示保持一致；本记录使用中文。

- 优先遵循用户或有权委派者明确指定的验收人及最新适用指示。否则，核对职责、委派来源和授权范围，不能凭头衔、名字、任务归属、状态写权限或自行声明的角色获得验收权。
- 沟通协调和交付验收可以由不同成员承担。没有明确验收人时，交付保留 `in_review`，向用户请求指定；明确保留给用户的验收及决定继续有效。
- 有协调者时，由其在沟通职责范围内汇总用户待答事项；没有协调者时，由任务负责人在已授权频道的主消息中直接提及用户，附原线程入口和答复后的下一步。已读不代表已答复。
- 创建新团队或角色时，记录沟通责任、验收范围及其授权来源、保留给用户的决定，不要求存在某个职位。

通用规则仍以 `packages/shared/src/raftCliGuide.ts` 为单一来源，覆盖托管和外部 Agent 两种指南。同步生成 CLI 手册、运行时提示快照及任务认领操作说明。具体协作约定见 [Agent 内部验收与用户待答事项](./agent-task-review-and-user-questions.md)。上一轮记录保留为历史，不将当时的 PM 委派当作所有团队的默认授权。

本次使用既有任务与消息能力，没有新增服务端验收权限模型或数据库字段；职责和授权规则通过提示与真实运行验证。

## 既有职责和记忆同步

通过正式 API 更新三名既有角色的职责说明，其余运行配置保持：

- 投资团队协调者：保留用户已明确授予的本项目内部验收职责，说明授权来源和范围，不因职位名称获得其他项目的验收权。
- vision 团队协调者：沟通协调不自动产生验收权，既有接手交付明确要求用户验收的部分继续保留。
- 小虾米：创建及交接团队时记录协调责任、验收人、委派范围和用户保留决定，不能把总体协调职责当作所有项目的验收授权。

九个业务 Agent 的 `MEMORY.md` 以及投资协调者的两份项目笔记，共十一份文件，新增英文通用规则。原有正文、历史状态、任务引用及具体项目委派均保留；其他二十八份既有记忆和笔记内容未改变。没有为此清空原生会话或工作目录，也没有更改既有任务状态。

## 真实运行验收

使用当前持久环境、新创建的两名 Codex Agent 和两个私有测试频道。所有样例为合成文本，不执行业务任务、账户操作或业务仓库修改。团队中没有 PM，也没有专职沟通协调者。

### 样例 A：新团队寻找有权验收的成员

执行者名为 `review-chief-1106`，职责只包括制作交付物，明确没有验收权；头衔不能代替授权。另一成员 `delivery-guide-1106` 的职责包含质量复核，由测试发起者明确委派其验收样例 A。任务请求未点名验收人，要求执行者根据已记录职责和授权找到合适成员。

执行者在 `role-auth-20261106` 创建原任务 ＃1，上传三行文本附件，将原任务转为 `in_review`，在原线程直接提及受托验收人。验收人实际下载附件，检查逐字节内容、三个换行和文件末尾换行，记录证据后完成原任务。数据库任务历史确认完成操作由受托验收人执行，且晚于其验收记录；原执行负责人没有改变。

- 原任务：`7366d9cf-5adb-4c62-8719-f2662b0f28e7`。
- 验收记录：`095df6e1-c187-407e-ab1f-03460160e429`。
- 真实附件：５８字节，SHA-256 为 `097943e772a3903ea570030caa357d7c2fa8ebf2e8a6d24316e7b75540c6fa83`。

验收期间一次开发热重载中断了验收人的回合。冻结运行时代码后，仅对本轮测试验收人做保留会话的普通重启，继续原请求；没有追加完成任务的指令，没有重置原生会话。随后上述验收通过。

### 样例 B：没有协调者，也没有受托验收人

`role-human-20261106` 中只有测试发起者和执行者；样例 A 的验收人不在该频道，且其授权不覆盖样例 B。

执行者提交原任务 ＃1 的真实附件后，保持 `in_review`，在频道主消息直接 `@本地用户`，说明当前结果，附原任务线程入口，请用户验收或指定受托验收人，并说明答复后的行动。此时执行回合已结束，数据库不存在该任务的完成事件，真实人类提及记录及通知时间均存在。
